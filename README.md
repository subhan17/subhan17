## 🚀 Recent Development — AI-Powered Test Automation Assistant

**[AI-Powered Test Automation Assistant — GenAI Practitioner Capstone](https://github.com/subhan17/ai-test-automation-capstone)**

A **uniform Python test-automation framework integrating Generative AI across the Software Testing Life Cycle (STLC)**, built around a multi-city flight-booking use case with UI, API and AI-assisted testing.

### What I designed and implemented

- **Playwright + Page Object Model** for UI automation
- **pytest-bdd / Gherkin** for behavior-driven specifications
- **REST API automation** using `requests` + `jsonschema`
- Parallel execution and retry using **pytest-xdist / pytest-rerunfailures**
- Data-driven testing using **Excel / openpyxl / pandas**
- **Self-healing locators** using primary selectors, fallbacks, semantic selectors, cached healing and bounded LLM-assisted healing
- **GenAI STLC layer** for requirements analysis, RTM generation, scenario generation, test planning, Gherkin generation and test-result analysis
- **Agentic browser automation** using browser-use / smolagents
- **Streamlit AI testing assistant**
- Provider-pluggable LLM architecture supporting **Anthropic, OpenAI, Gemini and Ollama**, including offline mock mode
- **Allure reporting**, screenshots on failure and structured logging
- **GitHub Actions CI/CD** with linting, deterministic API/hybrid test execution and artifact publishing
- Environment-aware configuration for **dev / QA / prod**

The framework currently contains **26 BDD scenarios**, deterministic API/hybrid suites, AI-assisted test generation and analysis, and a complete CI workflow.
